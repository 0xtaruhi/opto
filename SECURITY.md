# Security policy

## Supported versions

Opto is pre-1.0 and currently supports only the latest revision of the default
branch. Security fixes are not backported to older revisions.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private
security-advisory reporting for this repository. Include affected revisions,
impact, reproduction steps, and any proposed mitigation. If private reporting
is unavailable, contact the maintainer through the email address in
`CITATION.cff` without attaching proprietary design or PDK data.

The maintainer will acknowledge a report within seven days, keep the reporter
updated while it is investigated, and coordinate disclosure after a fix is
available. Never include license credentials, confidential netlists, or
foundry data in a report.
